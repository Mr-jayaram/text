VoiceScribe Guide & Browser Requirements

🚀 How Continuous Voice-to-Text Works

This application utilizes the W3C Web Speech API with an intelligent self-healing continuous loop. By default, web browsers limit continuous recognition sessions to short intervals of speech or silence. VoiceScribe safely catches automatic session closures and seamlessly restarts the microphone without discarding your previously dictated text or causing duplicate words.

🌐 Internet Connection Requirement

In Google Chrome and Chromium-based browsers, the Web Speech API transmits audio to Google's cloud speech recognition engines for high-accuracy processing. Therefore, an active internet connection is required for speech recognition to function.

💻 Browser & Localhost / HTTPS Requirements

  • Supported Browsers: Google Chrome (Desktop & Android), Microsoft Edge, Brave, Opera. (Firefox and Safari do not support the full Web Speech API recognition interface).
  • Security Policy: Web browsers strictly require microphone access to be served via localhost (e.g. http://127.0.0.1:5500 via VS Code Live Server) or a secure https:// origin. Opening the file directly via file:/// may block microphone permissions in some Chrome installations.

🛠️ Quick Tips for Best Results

  • Select your preferred dialect (English India/US, Tamil, or Hindi) before starting.
  • Use a clear external microphone or headset for superior recognition in noisy rooms.
  • Click Pause if you need to talk to someone else without losing your session.
  • Click Stop when you are finished; this cleanly turns off the microphone and halts auto-restart.
